# Experiment 1

## Title
Hello World Application using Node.js

## Description
This project is a simple Node.js application that displays "Hello World" in the browser.

## Technologies Used
- Node.js
- JavaScript

## How to Run
1. Install Node.js
2. Open the project folder
3. Run:
   npm install
4. Start the server:
   node server.js
5. Open:
   http://localhost:3000
